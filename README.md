# 🧠 TCAS 70 รอบ 1 Portfolio (จิตวิทยา) - Mobile Web

เว็บสรุปข้อมูลการรับสมัคร TCAS 70 รอบ 1 Portfolio สาขาวิชาจิตวิทยา (4 มหาวิทยาลัย: มศว, เกษตรศาสตร์, ธรรมศาสตร์, ศิลปากร) ออกแบบให้เปิดอ่านง่าย สวยงาม ลื่นไหลบนสมาร์ทโฟน พร้อมระบบ Sync ข้อมูลจาก Excel อัตโนมัติ

---

## ✨ ฟีเจอร์เด่นสำหรับเพื่อนที่เปิดดูบนมือถือ

1. **Card Layout & สีย่อยประจำสถาบัน:** อ่านง่าย ไม่ต้องเลื่อนตารางกว้าง ๆ ใน Excel
2. **ปุ่ม "แชร์สรุปเข้า LINE":** กดปุ่มเดียว คัดลอกข้อความสรุปของมหาลัยนั้นพร้อมส่งเข้าแชท LINE ได้ทันที
3. **ตัวกรอง & ค้นหาอัจฉริยะ:** ค้นหาตามชื่อมหาลัย, แขนง (คลินิก, พัฒนาการ, ชุมชน, ธุรกิจ), เกรด GPAX
4. **โหมดเปรียบเทียบ (Compare Mode):** เลือกเทียบข้อมูล 2 สถาบันแบบเคียงข้างกัน
5. **Checklist & ทริกเตรียมพอร์ต:** สรุปสิ่งที่ต้องเตรียม เช่น กิจกรรม Empathy, คอร์สออนไลน์ ThaiMOOC, ระบบ TCASFolio
6. **บันทึกรายการโปรด (Bookmark):** บันทึกมหาลัยที่สนใจไว้ในเครื่อง

---

## 🔄 วิธีการ Sync ข้อมูลเมื่อแก้ไขไฟล์ Excel

ไฟล์ข้อมูลต้นฉบับอยู่ที่:
`E:\OneDrive\Projects\Other Task\สรุป_TCAS70_Port_จิตวิทยา.xlsx`

### วิธีที่ 1: ดับเบิ้ลคลิกเดียวจบ (แนะนำ ⭐)
- ดับเบิ้ลคลิกไฟล์ `sync-and-deploy.bat` ในโฟลเดอร์นี้
- สคริปต์จะดึงข้อมูลจาก Excel มาอัปเดตใส่เว็บทันที (และถ้าเชื่อม GitHub ไว้ จะส่งขึ้น Vercel ให้อัตโนมัติ)

### วิธีที่ 2: โหมดตรวจจับอัตโนมัติ (Watcher)
- ดับเบิ้ลคลิกเปิด `watch_excel.py` ทิ้งไว้
- เมื่อใดก็ตามที่พี่เอเปิด Excel แล้วกด **Save (Ctrl + S)** ข้อมูลบนเว็บจะอัปเดตทันทีแบบเรียลไทม์

### วิธีที่ 3: สั่งผ่านคำสั่ง
```bash
python sync_data.py
```

## 🚀 วิธีเปิดดูเว็บไซต์ในเครื่อง / ในมือถือ (Local)

1. ดับเบิ้ลคลิกไฟล์ `start-dev.bat` หรือพิมพ์คำสั่ง:
   ```bash
   npm run dev
   ```
2. หน้าต่างจะแสดง URL เช่น `http://localhost:3000` และ `Network: http://192.168.x.x:3000`
3. พี่เอสามารถเอามือถือที่ต่อ Wi-Fi เดียวกัน สแกนหรือพิมพ์ URL Network เพื่อดูบนจอมือถือจริงได้ทันทีค่ะ

---

## 🌐 วิธีนำไป Deploy บน Vercel (ฟรี & ง่ายมาก)

1. นำโฟลเดอร์นี้ขึ้น **GitHub** ของพี่เอ
2. ไปที่ [vercel.com](https://vercel.com) ล็อกอินด้วย GitHub
3. กด **"Add New..."** -> **"Project"**
4. เลือก Repository นี้ -> กดยืนยัน **"Deploy"** (Vercel จะตรวจพบเป็น Vite อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม)
5. ได้ URL สวย ๆ (เช่น `tcas70-psychology.vercel.app`) ส่งให้เพื่อนเปิดดูจากที่ไหนก็ได้ทั่วโลก!
